# ⏰ Analog Clock

A minimalist and elegant real-time analog clock built using HTML, CSS, and JavaScript.

## 📌 About The Project

This project is a simple analog clock that displays the current local time using hour, minute, and second hands.

The clock numbers are dynamically generated using JavaScript, and the hands rotate based on the current time.

## ✨ Features

- Real-time clock functionality
- Dynamic generation of clock numbers
- Accurate hour, minute, and second hand rotation
- Minimalist dark-themed design
- Glassmorphism effect
- Responsive and centered layout
- Pure HTML, CSS, and JavaScript

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### Installation

1. Clone the repository:

   ```bash
   git clone (https://github.com/leilasharifidev/analog-clock.git)
   ```

2. Navigate to the project folder:

   ```bash
   cd analog-clock
   ```

3. Open `index.html` in your browser.
